# Архитектура проекта DONTFLOAT

## Обзор системы

DONTFLOAT - это аудиоанализатор и корректор BPM, построенный на Qt6 с использованием паттерна Command Pattern.

## Основные компоненты

### MainWindow
- **Роль**: Центральный компонент приложения
- **Ответственность**:
  - Управление всеми UI элементами
  - Обработка загрузки аудио через QMediaPlayer
  - Сохранение настроек через QSettings
  - Координация работы всех подсистем

### WaveformView
- **Роль**: Визуализация звуковой волны
- **Ответственность**:
  - Отображение меток цикла A и B
  - Масштабирование и навигация
  - Обработка пользовательского ввода
  - Синхронизация с позицией воспроизведения

### PitchGridWidget
- **Роль**: Piano roll под основным таймлайном
- **Статус**: **Видна по умолчанию**; `Ctrl+G` или меню **Вид**; `QSettings` → `pitchGridVisible`
- **Движок**: `PianoRollEngine` — viewport, beat grid, snap, подсветка тональности в легенде
- **Ответственность**:
  - Синхронизация с WaveformView (zoom, offset, каретка, BPM, длина таймлайна)
  - Отрисовка piano roll, тактовой сетки, каретки (поверх легенды)
  - Легенда нот справа (полупрозрачная); контент таймлайна без колонки легенды
  - Плашка «Анализировать» для определения тональности после загрузки
  - Ввод: ЛКМ — seek/выбор ноты; ПКМ — pan; колёсико — вертикальный скролл; Ctrl+колёсико — zoom
  - Вертикальный скроллбар (overlay слева) с динамической прозрачностью
  - Разрез нот: `S` по каретке и режим «Разделить» (клик по ноте); режим реза — `CutMode::SnapToGrid` / `CutMode::Free`
  - Сам разрез виджет не применяет: он шлёт `noteSplitRequested(noteIndex, sample)` хосту

### PianoRollToolbar
- **Роль**: панель кнопок под пианороллом (макет `MARKDOWN/example_panel_buttons.svg` × 1.5)
- **Ответственность**:
  - Кнопка «Разделить» (checkable) и взаимоисключающая пара «Вдоль сетки» / «Свободный рез»
  - Иконки — SVG из `resources/icons/` (`trimmer`, `along_the_grid`, `free_cut`); фон и состояния — через `setStyleSheet`
  - Только UI: состояние уходит в `PitchGridWidget`, режим реза сохраняется в `QSettings`

### BPMAnalyzer
- **Роль**: Анализ BPM с использованием алгоритмов Mixxx
- **Ответственность**:
  - Детекция битов
  - Вычисление отклонений ритма
  - Интеграция с системой команд

### KeyAnalyzer
- **Роль**: Анализ тональности аудиофайлов
- **Ответственность**:
  - Поддержка мажорных и минорных тональностей
  - Интеграция с qm-dsp библиотекой

### BeatVisualizer
- **Роль**: Визуализация ударных инструментов
- **Ответственность**:
  - Цветовое кодирование по типам ударных
  - Спектрограмма для анализа частот
  - Энергетическая кривая ударных
  - Отображение силуэта ударных поверх волны

### WaveformAnalyzer
- **Роль**: Анализ волновой формы аудио
- **Ответственность**:
  - Интеграция с Mixxx библиотеками
  - Обработка аудиоданных для визуализации
  - FFT анализ
  - Фильтрация сигнала

### MarkerEngine
- **Роль**: Данные и UI меток растяжения
- **Файлы**: `include/markerengine.h`, `src/markerengine.cpp`
- **Ответственность**:
  - Структуры `MarkerData` (данные меток) и `Marker` (UI)
  - Валидация и сортировка меток
  - Правила: нулевая метка статична, минимальный сегмент 50 мс, без дубликатов
  - `MarkerUtils::detectOnsetSamples` — позиции транзиентов по огибающей;
    общий алгоритм кнопки «OD» для главного окна и плагинов

### MidiExporter / MidiImporter
- **Роль**: обмен нотами пианоролла со стандартным MIDI (SMF формата 0, 480 тиков на четверть)
- **Файлы**: `include/midiexporter.h`, `src/midiexporter.cpp`,
  `include/midiimporter.h`, `src/midiimporter.cpp`
- **Ответственность**:
  - Экспорт: сэмплы → тики по BPM и частоте дискретизации, нулём файла берётся начало тактовой сетки
  - Импорт референса: разбор SMF (running status, темп мета-событием `0x51`), три режима тайминга —
    `KeepAsIs` (темп самого файла), `FitToBpm` (темп проекта), `AlignAndFitToBpm` (плюс сдвиг первой ноты
    на начало сетки)
  - `MidiImporter::detectKey` — тональность референса по взвешенной длительностями хроме
    через `KeyAnalyzer::detectKeyFromChroma`
  - `MidiImporter::analyzeKeyPerBar` — потактовая тональность референса: хрома по звучанию нот
    внутри такта, такт без нот держит тональность предыдущего, итог собирает общий с аудио
    `KeyAnalyzer::summarizeBarKeys` (доминирующая тональность, регионы, признак модуляции)
  - Референсные ноты не редактируются: `PitchGridWidget` рисует их серым позади своих нот

### Интерфейс плагинов (`plugins/ui/`)
- **Роль**: тот же интерфейс, что в главном окне, внутри DAW
  (макет `MARKDOWN/example_plugin_dontfloat.svg`)
- **Файлы**: `dontfloat_plugin_editor_shell.*` (шапка + статусбар),
  `dontfloat_plugin_theme.*` (Fusion + тёмная палитра из `src/main.cpp`),
  `dontfloat_editor_content.h` (что оболочка спрашивает у редакции),
  `dontfloat_{full,scratch,pitch}_editor.*`
- **Ответственность**:
  - Оболочка: имя редакции, кнопки `OD` / `<` / `BG` / `>` и транспорт
    ▶ ■ метроном `A` `B` ↺, один статусбар (сигнал `statusMessage`)
  - Тема: глобально — только для своего `QApplication`; при хостовом цикле Qt
    красится лишь поддерево редактора
  - Содержимое: волна + скроллбар (Scratch), поля тональностей + пианоролл +
    `PianoRollToolbar` (Pitcher), обе секции сразу (Full)
  - Мультимедиа (прослушивание, метроном) — лениво: инициализация при
    построении редактора проворачивает вложенный цикл событий хоста
  - Захват дорожки адресуется таймлайном (`TrackToolSession::writeHostFrames`):
    буфер повторяет дорожку DAW, разрыв между блоками начинает новый проход
  - Ноты одного экземпляра — референс для соседних: `SharedNoteBoard`
    (`plugins/core/dontfloat_shared_notes.*`), общая на процесс доска
    «id экземпляра → последние ноты + отметка ревизии»; редактор опрашивает её
    таймером и забирает публикацию не от себя
  - Анализ — при каждом изменении содержимого (кнопок анализа нет);
    `computeContentFingerprint` / `detectContentShift` отличают перенос клипа,
    и тогда метки, сетка, точки цикла и ноты сдвигаются без пересчёта

### TimeStretchProcessor
- **Роль**: Обработка временного растяжения аудио по меткам
- **Файлы**: `include/timestretchprocessor.h`, `src/timestretchprocessor.cpp`
- **Ответственность**:
  - Алгоритмы растяжения/сжатия (тонкомпенсация через Rubber Band R3 / `RubberBandOffline`)
  - Методы: `applyMarkerStretch()`, `calculateSegments()`, `validateMarkers()`
  - Работа с `MarkerData`, результат в `StretchResult`

### RubberBandOffline
- **Роль**: Офлайн time-stretch одного канала (обёртка Rubber Band Library v4)
- **Файлы**: `include/rubberband_offline.h`, `src/rubberband_offline.cpp`, `cmake/RubberBand.cmake`
- **Ответственность**:
  - `stretchMono()` — движок R3 (`OptionEngineFiner`), вызывается из `processWithPitchPreservation()`
  - Статическая lib `rubberband_single` из `thirdparty/rubberband/single/`

### TimeStretchCommand
- **Роль**: Команды undo/redo для операций растяжения по меткам
- **Файлы**: `include/timestretchcommand.h`, `src/timestretchcommand.cpp`
- **Ответственность**:
  - Сохранение состояния меток и аудио до применения
  - Отмена и повтор через QUndoStack
  - Интеграция с MainWindow и WaveformView

### TimeUtils
- **Роль**: Утилиты для работы со временем
- **Ответственность**:
  - Конвертация между форматами времени
  - Вычисления временных интервалов
  - Форматирование временных меток
  - Преобразование сэмплов в время и обратно

### MetronomeController
- **Роль**: Независимый контроллер метронома
- **Ответственность**:
  - Синхронизация с BPM трека
  - Управление сильными и слабыми долями
  - Независимая работа от воспроизведения
  - Настройка громкости долей
  - Автоматическая остановка при завершении трека

## Система команд (Command Pattern)

### AudioCommand
- Загрузка и сохранение аудиофайлов
- Валидация форматов
- Обработка ошибок

### BeatFixCommand
- Исправление отклонений битов
- Интеграция с QUndoStack
- Поддержка отмены/повтора

### TimeStretchCommand
- Применение растяжения по меткам (Ctrl+T)
- Сохранение исходных данных для отмены
- Интеграция с QUndoStack

## Консольный режим

### Реализация
- Отдельная функция `runConsoleMode()`
- Использование `QCoreApplication` для консольного режима
- Синтетические данные для демонстрации BPM анализатора

### Командная строка
```bash
DONTFLOAT.exe -c -f <файл> [опции]
```

### Опции
- `--min-bpm`: Минимальный BPM (по умолчанию: 60)
- `--max-bpm`: Максимальный BPM (по умолчанию: 200)
- `--mixxx`: Использовать алгоритм Mixxx
- `--fast`: Быстрый анализ
- `--variable-tempo`: Предполагать переменный темп

## Система сборки

### CMake (предпочтительно)
- Минимальная версия: 3.16
- Стандарт C++: 17
- Qt6 модули: Core, Gui, Widgets, Multimedia, MultimediaWidgets

### qmake (альтернатива)
- Используется для совместимости с Qt Creator
- Поддерживаются оба формата сборки

## Обработка аудио

### Поддерживаемые форматы
- WAV, MP3, FLAC
- Частота дискретизации: любая (нативная частота файла, без принудительного ресемплинга)
- Битность: 8/16/24/32-bit и float (конвертируется во float при загрузке)
- Каналы: Моно, Стерео

### Технические требования
- Декодирование в 32-bit float для точности
- Нормализация аудиоданных
- Асинхронная обработка для производительности
- Эффективное управление памятью

## Настройки и локализация

### QSettings
