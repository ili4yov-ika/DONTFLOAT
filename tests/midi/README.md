# MIDI-фикстуры (`tests/midi`)

Эталонные пары **MIDI + WAV** для ручной и автоматической проверки pitch-детекции, пианоролла и диапазона C0+.

## `test_1` — хроматический ladder по длительностям и октавам

| Файл | Назначение |
|------|------------|
| [`test_1.mid`](test_1.mid) | Партитура (ground truth нот) |
| [`test_1.wav`](test_1.wav) | Рендер той же партитуры |

### Аудио (`test_1.wav`)

| Параметр | Значение |
|----------|----------|
| Каналы | 2 (стерео) |
| Разрядность | 24 bit |
| Sample rate | **192 kHz** |
| Длительность | **≈ 63.43 s** (12 178 176 фреймов) |
| Размер | ≈ 73 MB |

Хвост WAV чуть длиннее последней MIDI-ноты (~61.7 s) — нормальный релиз/тишина после рендера.

### MIDI (`test_1.mid`)

| Параметр | Значение |
|----------|----------|
| Формат | SMF **1** (несколько треков) |
| Треки | `SID` (все ноты), `Kicker` (пустой по note events) |
| Division | **128** ticks per quarter note |
| Tempo | **140 BPM** (meta `0x51`, µs/qn ≈ 428 571) |
| Meter / key meta | **нет** (`time signature` / `key signature` не заданы) |
| Канал | 0 |
| Velocity | везде **64** |
| Note on/off | 238 / 238 на треке `SID` |
| Уникальные ноты | **216** (по паре start tick + pitch); 22 начала удвоены unison’ом (два note-on на одной высоте и тике) |

Длительности (в долях четверти при 128 TPQN / 140 BPM):

| Ticks | Доля | Секунды | Кол-во (уник.) |
|------:|------|--------:|---------------:|
| 32 | 1/16 | 0.107 | 32 |
| 64 | 1/8 | 0.214 | 32 |
| 96 | 3/16 (dotted 1/8) | 0.321 | 32 |
| 128 | 1/4 | 0.429 | 96 |
| 256 | 1/2 | 0.857 | 12 |
| 512 | целая | 1.714 | 12 |

Диапазон высот: **C0 (MIDI 12) … B8 (MIDI 119)** — 48 различных pitch class+octave.

Тональность формально не задана: материал **хроматический**, без устойчивого мажора/минора. Для KeyAnalyzer ожидаемо «шумная» / плавающая оценка; фикстура в первую очередь для **pitch**, а не для key.

### Структура по времени (логическая)

1. **0–≈5.1 s — duration ladder на C4…D#4**  
   Четырехзвучный хроматический мотив `C–C#–D–D#` с удлинением нот: 1/16 → 1/8 → 3/16 → 1/4, затем половинная `C4`.

2. **≈5.1–≈20.6 s — мелодия + длинные педали**  
   Короткие четверти (`D4 E4 F4 B4 A4 …`) поверх длинных целых (`C3`, `B5`, `C4`, `C3`, `C2`, `C1`, `C0` и т.д.), затем восходящий фрагмент с октавными слоями (`C2`/`F2`, `C3`/`F3`, … до `C5`).

3. **≈20.6–≈48 s — тот же duration ladder, сдвиг вниз по октавам**  
   Повтор паттерна `C–C#–D–D#` (+ хвост `D E F B`) на регистрах **C3**, **C2**, **C1**, **C0**.

4. **≈48–≈54.9 s — параллель C3 + C0**  
   Тот же ladder одновременно в двух октавах (полифония / unison по ритму).

5. **≈54.9–≈61.7 s — ladder вверху**  
   `C8–C#8–D8–D#8` … до `B8` — проверка верхнего края диапазона.

### Зачем фикстура в DONTFLOAT

- Проверка **pitch detector** на коротких (1/16) и длинных (целая) нотах при 140 BPM.
- Покрытие **диапазона C0…B8** (в т.ч. низ, где раньше сетка обрывалась на C1/C2).
- Полифония: педаль + мелодия; параллельные октавы C3∥C0.
- Ground truth для сравнения блоков пианоролла с MIDI (start/end в сэмплах при 192 kHz).
- Не ideal для теста «одна тональность» / модуляции — материал хроматический.

### Быстрая сверка MIDI ↔ WAV

```text
BPM (MIDI)     140
Последняя нота ~61.71 s
WAV duration   ~63.43 s
SR WAV         192000 → удобно: 1 tick @ 128 TPQN, 140 BPM
               = (60/140)/128 с ≈ 3.348 ms
               ≈ 643 сэмпла @ 192 kHz
```

### Примечания

- Трек `Kicker` в файле есть, но **не содержит** note on/off — при импорте ориентироваться на `SID`.
- Часть нот в MIDI записана **дважды** на одном тике/высоте (unison duplicate); для эталона дедуплицировать по `(start_tick, pitch)`.
- Файл WAV тяжёлый (~73 MB) из‑за 192 kHz / 24-bit stereo; для CI при необходимости можно сделать даунсэмпл-копию, оригинал оставлять как reference render.

## Автотесты на `test_1`

| Цель | Таргет CTest | Файл |
|------|----------------|------|
| Питчер (`PitchDetector`) vs MIDI | `midi_pitch_test` | `tests/midi_pitch_test.cpp` |
| Неровные доли (`findUnalignedBeats`) | `midi_beat_deviation_test` | `tests/midi_beat_deviation_test.cpp` |

Общий разбор SMF: `tests/midi_smf.h`.

```powershell
cmake --build build/Desktop_Qt_6_9_3_MSVC2022_64bit-Release --config Release --target midi_pitch_test midi_beat_deviation_test
ctest --test-dir build/Desktop_Qt_6_9_3_MSVC2022_64bit-Release -C Release -R "midi_(pitch|beat_deviation)_test" --output-on-failure
```

`midi_pitch_test` декодирует WAV, даунсэмплит до ~48 kHz и анализирует первые ~8 с (duration ladder C4…).  
`midi_beat_deviation_test` строит четвертную сетку из MIDI в масштабе 192 kHz и проверяет идеальное выравнивание + детекцию искусственных сдвигов.
