# Функции DONTFLOAT

*Версия: 0.0.0.1 · Последнее обновление: 14 июня 2026*

Подробное описание всех возможностей приложения.

## 🎵 Аудио обработка

### Поддерживаемые форматы
- **WAV** - несжатый аудио формат
- **MP3** - сжатый аудио формат
- **FLAC** - сжатие без потерь

### Технические характеристики
- **Частота дискретизации**: любая — нативная частота файла (без принудительного ресемплинга)
- **Битность**: 8/16/24/32-bit и float (конвертируется во float при загрузке)
- **Каналы**: Моно, Стерео
- **Декодирование**: 32-bit float для точности
- **Сохранение**: WAV PCM 16-bit

### Загрузка и сохранение
- **Загрузка**: Drag & Drop или меню "Открыть"
- **Сохранение**: Автоматическое сохранение изменений
- **Предварительный просмотр**: Мгновенная загрузка для воспроизведения
- **Валидация**: Проверка корректности файлов

## 🎛️ Визуализация волны

### Режимы отображения волны

Переключаются через меню **Вид → Вид звуковой волны**:

| Режим | Описание |
|-------|----------|
| **Звуковые пики** | Стандартное отображение амплитуды по каналам с цветовой индикацией (синий — низкие, средние, высокие частоты) |
| **Спектрограмма** | Тепловая карта частотного содержимого по каждому каналу; синхронизирована с зумом и прокруткой |

### Настройки спектрограммы

Открываются через **Настройки → Настройки отображения спектрограммы...**. Диалог немодальный — изменения видны сразу.

| Параметр | Значения | Описание |
|----------|----------|----------|
| **Размер окна FFT** | 256 / 512 / 1024 / 2048 | Больше → выше разрешение по частоте, ниже по времени |
| **Временное разрешение** | 64–1024 кадров | Больше → детальнее по времени, медленнее генерация |
| **Частотные полосы** | 32–256 | Больше → детальнее по частоте |
| **Цветовая схема** | Тепловая карта / Оттенки серого / Холодная | Отображение интенсивности |

Каналы (моно/стерео) показываются отдельными полосами с разделяющей линией, как в режиме пиков.

### Отображение (режим звуковых пиков)
- **Цвет**: Индиго с прозрачностью
- **Стиль**: Плавные кривые
- **Масштабирование**: От 1x до 1000x
- **Адаптивность**: Автоматическое масштабирование под размер окна
- **Полноэкранный режим**: При скрытии питч-сетки волна заполняет всё доступное пространство
- **Поле тональности**: Интерактивное поле для отображения и выбора тональности
- **Точная синхронизация кареток**: Каретки воспроизведения точно синхронизированы между волной и питч-сеткой при любых действиях (прокрутка, масштабирование, навигация)
- **Питч-сетка**: По умолчанию **видна**; скрыть/показать — `Ctrl+G` или меню **Вид** (состояние сохраняется в настройках)
- **Отступы таймлайна**: одинаковые горизонтальные margins (**4 px**) у волны и питч-сетки (`UiConstants::kTimelineHorizontalMarginPx`), чтобы ширины рабочих полей совпадали

### Навигация
- **Горизонтальная прокрутка**: Скроллбар и перетаскивание
- **Вертикальная прокрутка**: Автоматическое масштабирование
- **Панорамирование**: Правый клик + перетаскивание
- **Переход к позиции**: Клик по волне

### Размер такта и тактовая сетка
- **Выбор размера**: В главном окне и в диалоге загрузки размер такта задаётся выпадающим списком: **4/4**, **3/4**, **1/4**, **2/4**, **6/8**, **12/8**.
- **Правило сетки**: Число долей (линий сетки) в такте определяется **знаменателем** размера такта (вторая цифра):
  - для размеров **X/4** (1/4, 2/4, 3/4, 4/4) — **4 доли** в такте;
  - для размеров **X/8** (6/8, 12/8) — **8 долей** в такте.
- **Длина такта**: 4/4 — 4 четверти, 3/4 — 3, 2/4 — 2, 1/4 — 1 четверть; 6/8 — 3 четверти (6 восьмых), 12/8 — 6 четвертей. Подпись позиции (такты и доли) согласована с этой сеткой.

### Визуальные элементы
- **Курсор воспроизведения**: Вертикальная линия с треугольником
- **Такты**: Белые яркие линии (границы тактов и номера тактов)
- **Биты (доли)**: Белые полупрозрачные линии; сильная доля — жирнее
- **Метки цикла**: Цветные вертикальные линии (A — зелёная, B — красная)
- **Отклонения битов**: Треугольные области (красные — растянутые доли, синие — сжатые). Основание треугольника на фактической позиции бита, вершина — на ожидаемой; отображаются при включённой опции и при отклонении ≥ 2%.
- **Силуэт ударных**: Жёлто-оранжевый полигон поверх волны (опция, отдельно от треугольников отклонений)

## 🎯 Управление циклами

### Установка меток
- **Точка A (начало)**: Зеленая вертикальная линия
- **Точка B (конец)**: Красная вертикальная линия
- **Область цикла**: Полупрозрачная заливка между метками

### Способы управления
- **Горячие клавиши**: A/B для установки, Shift+A/B для удаления
- **Кнопки**: ЛКМ для установки, ПКМ для удаления
- **Контекстное меню**: Дополнительные опции
- **Визуальная обратная связь**: Изменение цвета кнопок

### Автоматические метки
- **По транзиентам (кнопка `OD`)**:
  - Анализирует энергетическую огибающую аудио и находит резкие всплески (транзиенты)
  - Ставит метки растяжения по основным транзиентам (ударные, атаки инструментов) с минимальным интервалом между срабатываниями, чтобы не перегружать трек метками

Привязка меток к тактовой сетке по всему треку доступна через **контекстное меню метки** («Переместить на тактовую сетку») и при выделении группы меток.

### Управление тактовой сеткой
- **Кнопка `<`**: сдвигает тактовую сетку на один удар назад.
- **Кнопка `BG`**: привязывает все существующие метки к текущей тактовой сетке.
- **Кнопка `>`**: сдвигает тактовую сетку на один удар вперёд.

### Функциональность
- **Валидация**: Проверка корректности диапазона
- **Синхронизация**: С позицией воспроизведения
- **Сохранение**: Автоматическое сохранение настроек
- **Восстановление**: При перезагрузке файла

## 📍 Система меток растяжения

### Описание
Система меток для **визуализации** будущего растяжения участков аудио и последующего применения эффекта с тонкомпенсацией. Метки отображаются как белые вертикальные линии с ромбиками в центре.

### Визуализация (до применения эффекта)
- **Вертикальная линия**: Светло-серая линия через всю высоту волны (для выделенных меток — ярко-белая)
- **Ромбик**: Небольшой ромб в центре линии; у выделенных меток ромб подсвечен белым
- **Цветовая индикация по сегментам**:
  - Синие углы ромба показывают участки, которые **будут сжаты** при применении
  - Красные углы ромба показывают участки, которые **будут растянуты** при применении
- **Коэффициенты**: Тонкие горизонтальные линии между метками с отображением коэффициента растяжения

### Управление
- **Создание метки**: Клавиша `M` в текущей позиции воспроизведения
- **Перетаскивание**: ЛКМ на ромбик и перетаскивание для изменения позиции
- **Автоматическое создание**: При создании первой метки автоматически создаются начальная (статичная) и конечная метки
- **Начальная метка**: Неподвижная метка в позиции 0
- **Конечная метка**: Подвижная метка в конце таймлайна, справа от неё нельзя создавать новые метки
- **Выделение**:
  - ЛКМ по ромбику — выделяет одну метку
  - ЛКМ + `Shift` — добавляет/убирает метки в группу выделения
  - `Ctrl+A` (если выделена одна метка) — выделяет все метки растяжения
- **Контекстное меню (ПКМ по метке)**:
  - **Переместить на тактовую сетку** — снэп одной или группы выделенных меток к ближайшей доле тактовой сетки
  - **Удалить метку / выделенные метки**

### Функциональность
- **Сжатие или разжатие тех или иных отрезков**: С помощью меток можно в ручную корректировать доли
- **Визуальная индикация**: Коэффициенты и цветовая индикация обновляются в реальном времени при перетаскивании меток
- **Предпросмотр в реальном времени**:
  - Для треков до ~5 минут в длину волна может пересчитываться на лету при перетаскивании (быстрый предпросмотр без тонкомпенсации)
  - Для очень длинных треков предпросмотр отключается, чтобы не тормозить интерфейс — в этом случае при перетаскивании меняются только метки, а применение происходит по Ctrl+T
- **Важно**: Аудио и форма волны **НЕ изменяются** до нажатия Ctrl+T (только визуальная индикация и, опционально, предпросмотр)

### Применение эффекта
- **Команда применения**: Ctrl+T («Применить сжатие-растяжение»)
- **Обработка**: `TimeStretchProcessor::applyMarkerStretch()` с тонкомпенсацией (Rubber Band Library v4, движок R3)
- **Результат**: Волна перерисовывается с новыми данными, метки обновляются под новую длину аудио
- **Воспроизведение**: QMediaPlayer переключается на обработанное аудио (временный WAV)
- **Отмена/повтор**: Ctrl+Z / Ctrl+Y через команду `TimeStretchCommand` в истории операций

## 🔍 Анализ BPM

### Алгоритмы
- **Mixxx onset detection**: Высокоточный алгоритм
- **Параметры**: stepSize=512, windowSize=1024
- **Точность**: Оптимизирован для электронной музыки
- **Обработка**: Асинхронная для производительности

### Визуализация
- **Отклонения битов**: Треугольные области (красные — растянутые доли, синие — сжатые). Основание на фактической позиции бита, вершина на ожидаемой; порог отображения по умолчанию 2%. Яркие/бледные цвета в зависимости от флага выравнивания.
- **Силуэт ударных**: Опциональный жёлто-оранжевый полигон по энергетической огибающей (отдельная опция).
- **Рекомендации**: Автоматические предложения исправлений
- **Статистика**: Количество найденных битов

### Управление
- **Автоанализ**: При загрузке файла
- **Ручная настройка**: Ctrl+↑/↓ для изменения BPM
- **Валидация**: Проверка корректности значений
- **Сохранение**: Настройки сохраняются между сессиями

## 🎼 Анализ тональности

### Функциональность
- **Потактовая полоса тональности** (`KeyModulationStrip`): над пианороллом поля ввода выровнены по таймлайну (Melodyne-style); одно поле на непрерывный регион тактов с одной тональностью
- **Потактовый анализ**: `KeyAnalyzer::analyzeKeyPerBar()` + объединение в `KeyRegion`; доминирующая модуляция также обновляет легенду пианоролла (`setPrimaryKey` / `setSecondaryKey`)
- **По умолчанию**: C Major (до анализа)
- **Анализ по запросу**: после загрузки трека над пианороллом показывается полупрозрачная плашка с кнопкой **«Анализировать»**; по нажатию кнопка сменяется progress bar, а в фоне определяются тональность (`KeyAnalyzer`, qm-dsp) и ноты (`PitchDetector`)
- **Ручной выбор**: клик / ПКМ по полю региона — `KeySelectionMenu` с полным списком тональностей
- **Визуальная индикация**: поля с подсветкой; легенда пианоролла подсвечивает ноты текущей тональности
- **Сохранение**: основная/модуляционная тональность для легенды сохраняются в `QSettings`
- **Удобное расположение**: полоса синхронизирована со scroll/zoom волны

### Поддерживаемые тональности
- **Мажорные**: C, C#, D, D#, E, F, F#, G, G#, A, A#, B
- **Минорные**: C, C#, D, D#, E, F, F#, G, G#, A, A#, B
- **Не определена**: Опция для неопределенной тональности

### Управление
- **Клик / ПКМ по полю региона**: меню выбора тональности
- **Несколько полей**: появляются на границах смены тональности по тактам
- **Автосохранение**: настройки легенды сохраняются автоматически
- **Компактный дизайн**: полоса интегрирована в интерфейс питч-сетки

## 🎼 Питч-сетка

### Статус и включение
- **По умолчанию видна** при первом запуске (примерно 75% волна / 25% питч-сетка).
- **Переключение**: `Ctrl+G` или меню **Вид → Убрать/Показать питч-сетку**.
- **Сохранение**: видимость записывается в `QSettings` (`pitchGridVisible`) и восстанавливается при следующем запуске.
- **Пропорции сплиттера**: состояние сплиттера сохраняется при видимой питч-сетке.
- **Горизонтальные отступы**: **4 px** слева и справа у контейнеров волны и питч-сетки (одинаковая ширина рабочих полей).
### Отображение
- **Piano roll**: горизонтальные ряды нот (белые/чёрные клавиши) с вертикальной прокруткой.
- **Легенда нот**: колонка справа (36 px), полупрозрачная подложка; ноты вне выбранной тональности отображаются бледно-серым.
- **Тактовая сетка**: вертикальные линии долей и тактов, синхронизированы с `WaveformView` (BPM, размер такта, `gridStartSample`); ширина контента таймлайна = ширина виджета минус колонка легенды.
- **Длина таймлайна**: совпадает с волной, включая хвост после меток time stretch (`displaySampleCount()`).
- **Каретка воспроизведения**: красная вертикальная линия с треугольником; выровнена с белой кареткой волны; рисуется поверх легенды; перемещение без привязки к тактам.

### Ноты (питчер)
- **Анализ нот**: кнопка «Анализировать» запускает фоновый детектор f0 (`PitchDetector`: автокорреляция с децимацией, медианное сглаживание, сегментация по полутонам); найденные ноты отображаются блоками на пианоролле.
- **Блоки нот**: синие — как определены анализом, оранжевые — с изменённой высотой; блоки с низкой уверенностью детектора полупрозрачнее.
- **Редактирование высоты**: перетаскивание блока по вертикали (snap к полутонам) или, при выделенной ноте, `↑`/`↓` — полутон, `Shift+↑`/`Shift+↓` — октава, `Esc` — снять выделение; правки попадают в общий undo/redo.
- **Прослушивание при удержании**: пока блок ноты зажат мышью, её сегмент играет по кругу и высота меняется на лету при перетаскивании вверх/вниз (varispeed-превью); основное воспроизведение на это время ставится на паузу.
- **Автопересчёт звука**: после каждой правки высоты (drag, `↑`/`↓`, undo/redo) звук пересчитывается в фоне (Rubber Band R3 + ресемплинг) и воспроизведение переключается на скорректированную версию — как при перетаскивании меток time stretch.
- **Warp от меток**: при перетаскивании меток time stretch на волне блоки нот сжимаются/растягиваются вместе с сегментами; при `Ctrl+T` новые координаты закрепляются; фоновый рендер объединяет растяжение и коррекцию высоты.
- **Закрепление коррекции**: `Ctrl+Shift+T` (меню **Правка → Применить коррекцию высоты нот**) применяет коррекцию окончательно (с undo); после этого ноты считаются «чистыми» (оранжевая подсветка снимается).

### Навигация и ввод
- **ЛКМ / перетаскивание**: выбор высоты (ряда ноты) и переход к позиции на таймлайне (если клик не попал в блок ноты).
- **ПКМ + перетаскивание**: горизонтальное панорамирование (синхронизируется с волной).
- **Колёсико**: вертикальная прокрутка по высотам нот.
- **Ctrl + колёсико**: масштабирование таймлайна (через `WaveformView::zoomAtPixelX()`, синхронно с волной).
- **Вертикальный скроллбар**: overlay слева (16 px); в покое ~90% непрозрачности, при приближении каретки плавно до ~50% в зоне 10 px справа от скролла.

### Синхронизация с волной
- Горизонтальный offset, zoom, позиция каретки, BPM, размер такта, начало сетки и длина таймлайна — из `WaveformView` через `MainWindow::syncPitchGridFromWaveform()` / `syncPitchGridTimelineWidth()`.
- Опорная ширина таймлайна: `waveformView->width()`; координаты масштабируются на фактическую ширину `PitchGridWidget`.

### Стилизация
- Поддержка тёмной и светлой цветовых схем (`setColorScheme`).
- Полоса потактовой тональности (`KeyModulationStrip`) расположена над панелью питч-сетки.

### Ограничения (текущая версия)
- Детектор нот монофонический (стерео сводится в моно); полифония — в backlog.
- Границы нот мышью не редактируются — длительность меняется только метками time stretch на волне.
- Запись и MIDI-импорт/экспорт нот не реализованы.
- Движок: `PianoRollEngine` (`include/pianoroll_engine.h`) — viewport, тактовая сетка, snap и подсветка тональности.
